// reader_rules.wb.txt -- every quiet rule the source reader applies.
//
// Exists to cover the transformations that happen before any pipeline logic
// runs, and that are invisible in the output unless you know to look:
//
//   * a '#' row is a comment and is dropped        (normalize_dataframe)
//   * a blank row truncates the sheet              (read_input_excels)
//   * a 'note' column is dropped entirely          (read_input_excels)
//   * a blank column header is dropped             (read_input_excels)
//   * a value containing '_' drops its row         (drop_underscore_values)
//   * '_output1' is stripped from numeric columns  (normalize_dataframe)
//   * an unknown method warns and becomes 'replace'
//   * scenario 'all' and year 1 always pass the whitelist
//
// This single workbook is the argument for the text fixture format: none of it
// is expressible in a binary workbook a reviewer cannot read, and half of it is
// about blank lines and '#' characters that CSV would swallow.

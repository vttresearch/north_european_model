//
// Exists to cover:
//   * build_from_to_columns turning country pairs into from_node/to_node
//   * create_p_gnn emitting one directional row per source row
//   * both ends of a link contributing to the node domain
//   * p_gnn's fake MultiIndex, which no single-country fixture can reach
//
// Two rows, one per direction, because the transfer format is directional: a
// link that only appears one way is a link that only carries power one way.
